# 가이드 작성 우선순위

가이드 하나가 구글 검색의 입구 하나다. 가이드가 없는 서비스는 검색에 거의 잡히지 않는다.

**주의:** 검색량 도구로 잰 숫자가 아니라 Claude 의 추정이다. 도메인을 연결하고 Search Console 데이터가
쌓이면(보통 1~2개월) 실제로 어떤 검색어로 들어오는지를 보고 순서를 고친다.

## 고른 기준

| 기준 | 이유 |
|---|---|
| **수요** | 많은 사람이 "how to hire …", "best … for …" 로 찾는 서비스 |
| **주문 금액** | 수수료가 첫 주문 금액의 25%(Pro 판매자는 70%)라 단가가 높을수록 유리 |
| **Vetted Pro 판매자** | 추천을 Pro 판매자로 채울 수 있어야 카드 품질과 수수료가 모두 좋다 |
| **우리 강점** | 운영자가 직접 경험한 분야(YouTube, 음악)는 글에 경험을 담을 수 있다 |
