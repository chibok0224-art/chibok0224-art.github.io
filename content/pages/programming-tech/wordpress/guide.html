What a good WordPress package includes

WordPress gigs cover everything from installing a theme to building a full custom site, plus fixes for existing sites. Whatever you order, the package should state:

  • Scope: a new site, a redesign, a fix, or a speed or security job.
  • Theme: which theme or page builder will be used, and whether it is free or needs a paid license.
  • Plugins: which ones will be installed, and who holds any paid licenses.
  • Number of pages and whether content upload is included.
  • Mobile layout checked on real phones, not just a narrow browser window.
  • Revisions and delivery time.
  • Handover: an admin account in your name, a list of plugins, and a short guide to editing pages.

How to brief a WordPress developer

A good brief helps the developer choose the right theme and keeps the plugin list short. Send:

  1. What the site must do: show services, take bookings, publish a blog, sell a few products.
  2. A page list with the content for each page, or a note on who will write it.
  3. Sites you like, with what you like about them.
  4. Hosting and domain details, or ask for a hosting recommendation you will sign up for yourself.
  5. For existing sites: a recent backup, a list of current plugins, and a clear description of the problem, with screenshots.
  6. Who will edit the site later, so the developer can choose an editor that person can use.

What drives the price

  • a ready-made theme versus a custom design built with a page builder or custom code
  • number of pages and whether the developer uploads your content
  • paid themes and plugins, and who pays for their licenses
  • features such as online stores, memberships, bookings or multiple languages
  • speed and security work
  • for fixes: how old and complex the existing site is

Red flags

  • The developer offers "free" premium themes or plugins from unofficial sources. These are a common way malware gets into WordPress sites.
  • You would receive only an editor account, not a full administrator account.
  • The developer will not list the plugins they plan to install.
  • Changes to a live site are made without a backup or a test copy.
  • The portfolio has no live sites you can open and test yourself.

Quick pre-order checklist

  • I know whether this is a new site, a redesign or a fix.
  • I have agreed on the theme and who holds any paid licenses.
  • I will receive a full administrator account and a plugin list.
  • For an existing site, I have a backup I know how to restore.
  • I know who will handle updates and backups after delivery.
